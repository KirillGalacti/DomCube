# DOM CUB

Лендинг и каталог проектов для DOM CUB - сайта о готовых модульных домах с полной отделкой, коммуникациями и возможностью оформления ипотеки.

## О проекте

Сайт представляет линейку модульных домов DOM CUB: от компактных решений до домов увеличенной площади. На главной странице собраны ключевые преимущества, каталог проектов, дополнительные услуги, используемые материалы, галерея работ и контакты для связи.

## Что есть на сайте

- каталог проектов CUB 12, CUB 18, CUB 24, CUB 29, CUB 29C, CUB 33, CUB 36, CUB 46 и CUB 65;
- отдельные страницы проектов с площадью, стоимостью, комплектацией, планировкой и фотографиями;
- блок преимуществ модульного строительства DOM CUB;
- описание материалов и инженерного наполнения;
- дополнительные услуги: веранда и модульная SAUNA CUB;
- форма обратной связи и страница благодарности после заявки.

## Технологии

- HTML5
- CSS3
- Bootstrap
- JavaScript / jQuery
- Fancybox
- PHP-обработчик формы

## Структура проекта

```text
DomCube/
|-- index.html          # главная страница
|-- thank.html          # страница благодарности
|-- sendform.php        # обработчик формы обратной связи
|-- cases_page/         # страницы отдельных проектов
|-- css/                # стили сайта
|-- js/                 # скрипты
|-- img/                # изображения и галерея
`-- logo/               # логотипы DOM CUB
```

## Запуск

Для просмотра сайта достаточно открыть `index.html` в браузере. Для работы формы обратной связи проект нужно разместить на хостинге с поддержкой PHP и настроенной отправкой почты.
